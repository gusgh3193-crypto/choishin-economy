## 사전 조치: detached HEAD 재발

업무 배정 전 저장소 상태를 확인한 결과, HEAD가 또다시 `main`이 아닌 detached 상태로
`ac18927`(2026-11-26 커밋)을 가리키고 있었고, 로컬 `main` 브랜치는 `713d509`(2026-11-24
커밋)에 멈춰 있었다. `git fetch origin main`으로 확인한 결과 원격 `origin/main`은 이미
`ac18927`이었다(실제 push 누락 없음). `git branch -f main ac18927 && git checkout main`으로
브랜치를 정상 위치로 되돌렸고, `git status`로 `On branch main, up to date with origin/main,
nothing to commit`을 직접 확인했다. 이 현상이 11-26, 11-27 이틀 연속 재발했으므로, 사장께
세션 종료 전 브랜치 정리 절차를 점검해보시길 권한다(특이사항 참고).
