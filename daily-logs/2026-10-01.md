**오늘 지시한 일**

  구조화 데이터 가이드라인이 권장하는 `dateModified`가 없음을 발견. frontmatter `updated` 필드가
  있으면 그 값을, 없으면 `datePublished`와 동일한 값을 `dateModified`로 채우도록 최소 수정 지시.
  `image` 필드는 현재 글에 이미지가 없어 이번 범위에서 제외하고 향후 과제로만 남기도록, 다른
  스크립트(`validate_posts.sh`/`generate_sitemap.sh`/`daily_check.sh`)는 건드리지 말도록 범위 한정.

**완료한 일 (마스터 재검증 완료, 개발팀은 Bash 도구가 없어 실행 검증을 못 했다고 정직하게 보고했고
마스터가 대신 직접 실행함)**
- `scripts/generate_jsonld.sh`를 마스터가 직접 Read/`git diff`로 재확인. 변경분은 정확히
  (1) `date_published` 계산 직후 `updated` frontmatter를 읽어 `date_modified`를 계산하는 6줄
  추가, (2) JSON 출력부에 `"dateModified": "${date_modified}",` 한 줄 추가뿐이며, `datePublished`/
  `keywords`/`author`/`publisher`/`url` 등 기존 로직과 출력 순서는 전혀 바뀌지 않았음을 확인했다.
  `git status --short` 기준 `validate_posts.sh`/`generate_sitemap.sh`/`daily_check.sh`는 전혀
  변경되지 않음(지시 범위 준수).
- **마스터가 직접 실행**: `bash scripts/generate_jsonld.sh` 실행 결과 `생성 완료` 메시지와 함께
  `EXIT_CODE:0`을 확인했다. 생성된 `seo/jsonld/interest-rate-impact.json`을 직접 Read로 열어
  `"dateModified": "2026-09-13"`이 `"datePublished": "2026-09-13"`과 동일한 값으로 정확히
  생성되었음을 확인했다(이 글 frontmatter에 `updated` 필드가 없으므로 예상대로 `datePublished`와

- **마스터가 직접 실행(회귀 확인)**: 이어서 `bash scripts/daily_check.sh` 전체를 실행해
