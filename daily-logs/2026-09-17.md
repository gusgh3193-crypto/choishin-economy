- **마스터가 직접 실행**: `bash scripts/daily_check.sh` 결과 —
  ```

  [2/3] sitemap/robots 생성: 생성 완료 (글 1건 반영)
  [3/3] JSON-LD 생성: 생성 완료 (1건)
  오늘의 사이트 점검 결과
  1) 글 규칙 검증 : 성공
  2) sitemap/robots 생성 : 성공
  3) JSON-LD 생성 : 성공
  ```

  재생성 후에도 기존 커밋 내용과 차이가 없어(git status에 미표시) 기존 산출물이 이미 최신 상태임을
