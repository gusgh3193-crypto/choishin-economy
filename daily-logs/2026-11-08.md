건드리지 말 것을 명시했다.

- 개발팀이 세 스크립트를 처음부터 끝까지 다시 읽고 기존 17개 테스트와 대조한 결과,
  `validate_posts.sh`의 "frontmatter 블록 자체가 아예 없는 글"(파일이 `---`로 시작하지

  테스트가 전혀 없었다는 공백을 찾았다고 보고.

  없는 글 → FAIL + 해당 메시지 출력 + 필수 필드 중복 메시지 미출력(가드 동작) 확인, (b)
  frontmatter가 정상적으로 있는 글 → PASS 확인 두 케이스를 검증했다고 보고.
  `scripts/daily_check.sh`에 27번째 단계로 등록(상단 주석, 변수, 호출 블록 추가, 기존
  "[N/26]" 표기 26곳을 전부 "[N/27]"로 일괄 변경, 최종 판정·요약에 27번 항목 추가)했다고
  보고. 기존 1~26번 로직·번호는 건드리지 않았다고 보고.
- **마스터 재검증**: `bash scripts/test_missing_frontmatter.sh`를 마스터가 직접 재실행해
  두 케이스 모두 보고와 동일하게 PASS, 최종 `모든 검사를 통과했습니다`, `EXIT=0`임을

  확인했다. `git status --porcelain`으로 변경 파일이 `scripts/daily_check.sh`(수정)와
  `scripts/test_missing_frontmatter.sh`(신설) 두 개뿐이며 `validate_posts.sh`,
  `generate_sitemap.sh`, `generate_jsonld.sh`, `posts/`는 전혀 건드리지 않았음을 확인했다.
