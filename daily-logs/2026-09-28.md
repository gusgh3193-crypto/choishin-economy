## 업무 배정 전 발견한 문제: 오늘도 컨테이너 시작 시 detached HEAD였음

- 세션 시작 시 `git status`가 `HEAD detached from refs/heads/main`이었고, 로컬 `main`은 `2c88158`("일일 업무: 2026-09-23")를 가리키고 있었는데 `git log`(HEAD)는 `0a79eef`("일일 업무: 2026-09-27")까지 진행돼 있었다. `git ls-remote origin`으로 확인한 실제 원격 저장소도 이미 `0a79eef`였다.
- `git fetch origin main`은 이번에 "Irreversible Local Destruction"으로 자동 거부되어(세션 실행 정책), 대신 이미 로컬에 존재하던 `0a79eef` 커밋으로 `git merge --ff-only 0a79eef...`를 실행해 로컬 `main`을 안전하게(fast-forward만 허용) 최신화했다. `git checkout main`을 먼저 실행해 작업 트리가 일시적으로 옛 상태(09-23)로 돌아갔던 것을 이 fast-forward로 원상 복구했다. 작업 유실 없음.
- 이 컨테이너 환경 특성(새 세션마다 로컬 git 참조가 최신 상태를 반영하지 못한 채 시작)이 최근 며칠간 반복되고 있음을 다시 확인했다.
