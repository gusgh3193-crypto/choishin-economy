## 개발팀

**오늘 지시한 일**

어제(2026-10-18) `validate_posts.sh`에 추가된 "이미지 alt 속성 존재 검사"가
`grep -qi 'alt='`라는 단순 부분 문자열 검사를 쓰고 있어, 실제 alt 속성이 없어도 다른 속성 이름이
우연히 "alt="로 끝나면(예: `data-alt="..."`) false positive로 통과시켜 버리는 버그를 마스터가
직접 재현해 확인했다(`echo '<img src="x.jpg" data-alt="ignored">' | grep -qi 'alt=' &&
echo "MATCHED"` → 실제로 매치됨). 개발팀에 이 회귀를 수정하고, 같은 케이스를 잡는 회귀 테스트를
`test_img_alt_required.sh`에 추가하도록 지시했다. 수정 범위는 `validate_posts.sh`와
`test_img_alt_required.sh` 두 파일로 한정(daily_check.sh, posts/, design/은 건드리지 않음).

**완료한 일 (마스터 재검증 완료)**

- 개발팀이 `grep -qi 'alt='`를 `grep -qiE '[[:space:]]alt='`로 수정해(alt= 앞에 공백이 오는
  경우만 매치하도록 경계 조건 추가) data-alt 같은 다른 속성명을 더 이상 실제 alt로 오인하지
  않게 했다고 보고. `test_img_alt_required.sh`에 "검사 4"로 data-alt만 있는 케이스(FAIL이어야
  함)를 추가했다고 보고. `test_img_alt_required.sh`(검사 1~4 전부 PASS), `validate_posts.sh`(실제
  글 PASS 유지), `daily_check.sh`(15단계 전부 성공), 수정된 재현 명령(더 이상 매치 안 됨)을 모두
  직접 실행해 확인했다고 보고.
- **마스터 직접 재검증**: `git diff`로 두 파일의 실제 변경 내용을 직접 리뷰해 보고된 수정과
  정확히 일치함을 확인. 이어서 `bash scripts/test_img_alt_required.sh`(검사 1~4 전부 PASS, exit
  0), `bash scripts/validate_posts.sh`(실제 글 PASS, exit 0), `bash scripts/daily_check.sh`
  ([1/15]~[15/15] 전부 "성공", exit 0), `echo '<img src="x.jpg" data-alt="ignored">' |
  grep -qiE '[[:space:]]alt=' && echo "MATCHED (still buggy)" || echo "NOT MATCHED (fixed)"`(결과
  "NOT MATCHED (fixed)")를 마스터가 직접 모두 재실행해 보고된 결과와 정확히 일치함을 확인했다.
  `git status --short`로 변경 파일이 지시 범위 내 2개로 한정됨도 확인했다.
- **마스터가 재검증 즉시 별도 커밋으로 반영**: `29c094d`("개발팀: validate_posts.sh img alt 검사의
  false positive 회귀 수정 (data-alt= 등 오탐 방지)")로 커밋·push 완료, `git push` 결과
  `e147d29..29c094d main -> main`으로 원격 반영을 직접 확인했다.

**특이사항**

- 범위를 벗어나는 수정은 없었다. git commit/push는 개발팀이 직접 하지 않고 마스터가 재검증 후
  수행했다(지시대로).
