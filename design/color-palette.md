# 최신경제 색상 팔레트 (디자인팀)

이 문서는 `design/style-guide.md` 7번 "접근성 고려사항"에 있는 추상적 규칙
(명도 대비 4.5:1 이상, 연한 회색 본문 금지 등)을 실제 hex 색상 코드로 구체화한
것이다. 아직 실제 사이트 CSS는 없는 단계이므로, 개발팀이 향후 배포 플랫폼과
CSS를 구현할 때 이 문서를 기준으로 삼는 것을 제안한다.

라이트모드만 다룬다(다크모드는 이번 범위 밖이며, 필요해지면 별도 문서로 검토한다).

---

## 1. 팔레트 요약 표

| 용도 | 색상 코드 | 비고 |
|---|---|---|
| 배경 (본문 페이지) | `#FFFFFF` | 순백. 장식 없는 담백한 톤 유지를 위해 별도 틴트를 주지 않는다. |
| 본문 텍스트 | `#333333` | 순검정(`#000000`) 대신 약간 부드러운 다크그레이로, 눈의 피로도를 낮춘다. |
| 소제목 H1 | `#1A1A1A` | 본문보다 살짝 더 짙게 해 위계를 색상으로도 약하게 구분한다(주 위계 수단은 style-guide.md 7번의 폰트 크기 규칙). |
| 소제목 H2 | `#1A1A1A` | H1과 동일 색상. 크기 차이(폰트 크기 1.3~1.5배)로만 위계를 구분하고 색상은 통일해 과한 장식을 피한다. |
| 링크 (방문 전) | `#0B5FA5` | 채도를 낮춘 블루. 인터넷 사용자에게 익숙한 "링크=파란색" 관습을 유지하되 원색(`#0000FF` 등)은 피한다. |
| 링크 (방문 후) | `#6A4C93` | 채도를 낮춘 퍼플. 방문 전/후 구분은 아래 "2-3. 방문 전/후 링크 구분 여부"에서 근거 설명. |
| 면책 문구/경고 박스 배경 | `#FFF3E0` | 옅은 앰버(호박색) 틴트. 금융 도메인에서 관용적으로 쓰이는 "주의" 색조를 채도를 낮춰 차용. |
| 면책 문구/경고 박스 텍스트 | `#6B3E00` | 박스 배경 위에서 충분한 대비를 내는 짙은 브라운. |
| 표(table) 헤더 배경 | `#F0F0F0` | 옅은 그레이. 본문 배경(`#FFFFFF`)과 구분되지만 튀지 않는 수준. |
| 표(table) 헤더 텍스트 | `#333333` | 본문 텍스트 색상을 그대로 재사용해 색상 종류를 최소화한다. |

## 2. 명도 대비 계산

### 2-1. 계산 방법

WCAG 2.x의 상대 휘도(relative luminance) 공식을 그대로 적용했다.

```
sRGB 채널값 c (0~255)를 c_s = c/255 로 정규화한 뒤:
  c_s <= 0.03928 이면  c_lin = c_s / 12.92
  c_s >  0.03928 이면  c_lin = ((c_s + 0.055) / 1.055) ^ 2.4

상대 휘도 L = 0.2126*R_lin + 0.7152*G_lin + 0.0722*B_lin

두 색의 대비비 = (L_light + 0.05) / (L_dark + 0.05)
  (L_light, L_dark는 두 색 중 더 밝은/어두운 쪽의 상대 휘도)
```

검증을 위해 잘 알려진 값(`#333333` on `#FFFFFF` ≈ 12.6:1, WebAIM 등 공개 대비
계산기에서 통용되는 값)과 직접 계산 결과를 대조했고 일치함을 확인했다.

### 2-2. 팔레트별 계산 결과

| 조합 | 전경 L | 배경 L | 대비비 | 기준 | 판정 |
|---|---|---|---|---|---|
| 본문 `#333333` / 배경 `#FFFFFF` | 0.03310 | 1.0 | **12.63:1** | 본문 4.5:1 | **통과** (여유 큼, AAA 7:1도 통과) |
| 소제목(H1/H2) `#1A1A1A` / 배경 `#FFFFFF` | 0.01033 | 1.0 | **17.41:1** | 큰 텍스트 3:1 / 본문 4.5:1 | **통과** (둘 다 여유 큼) |
| 링크(방문 전) `#0B5FA5` / 배경 `#FFFFFF` | 0.10976 | 1.0 | **6.57:1** | 본문 4.5:1 | **통과** (AAA 7:1엔 근소 미달) |
| 링크(방문 후) `#6A4C93` / 배경 `#FFFFFF` | 0.10341 | 1.0 | **6.85:1** | 본문 4.5:1 | **통과** (AAA 7:1엔 근소 미달) |
| 면책 박스 텍스트 `#6B3E00` / 박스 배경 `#FFF3E0` | 0.06571 | 0.90752 | **8.28:1** | 본문 4.5:1 | **통과** (AAA 7:1도 통과) |
| 표 헤더 텍스트 `#333333` / 헤더 배경 `#F0F0F0` | 0.03310 | 0.87148 | **11.09:1** | 본문 4.5:1 | **통과** (AAA 7:1도 통과) |

모든 조합이 style-guide.md 7번의 "본문 4.5:1 이상" 기준을 충족하며, 소제목처럼
큰 텍스트 취급이 가능한 항목은 3:1 기준도 넉넉히 충족한다. `#999` 이하의 연한
회색은 어느 항목에도 사용하지 않았다(본문 `#333333`은 계산상 루미넌스
0.0331로 `#999`(약 0.318) 대비 훨씬 어둡다).

### 2-3. 방문 전/후 링크 구분 여부

방문 전(`#0B5FA5`)·방문 후(`#6A4C93`) 색을 구분해서 제안한다. 이유:

- 최신경제 블로그는 같은 주제 글을 서로 링크하는 구조(관련 글 링크 등)가 될
  가능성이 높다. 이미 읽은 글과 안 읽은 글을 구분할 수 있으면 독자의 재방문
  탐색(wayfinding)에 도움이 된다.
- 다만 WCAG 자체는 방문 전/후 구분을 요구하지 않으므로, 개발팀이 구현 단계에서
  글 목록 등 링크가 드문 화면에서는 구분을 생략해도 무방하다(필수 규칙 아님,
  권장 사항).
- 두 색 모두 대비비가 6.5:1 이상으로 통일된 안정권에 있어, 어느 쪽을 먼저
  적용해도 가독성 문제는 없다.

### 2-4. 색상 외 추가 단서 필요성

style-guide.md 7번 "링크/강조 색상" 규칙("색상만으로 정보를 구분하지 않는다")에
따라, 링크는 색상뿐 아니라 **밑줄(underline)**을 함께 적용할 것을 권장한다.
색맹 사용자는 방문 전/후 색상 차이를 구분하지 못할 수 있으므로, 밑줄 굵기나
스타일(예: 방문 후 밑줄을 점선으로) 같은 비색상 단서를 보조로 검토할 수 있다.
다만 이는 개발팀이 실제 CSS를 만들 때 결정할 세부 사항이다.

## 3. 색상 선택 이유 / 톤앤매너 근거

- **배경·본문·소제목은 그레이스케일로 통일**했다. style-guide.md가 강조하는
  "담백한 서술, 장식 최소화" 톤과 맞추기 위해 페이지 전반의 기본 색은 채도를
  주지 않았다. 화려한 색을 배경이나 본문에 쓰면 경제 정보 글의 신뢰도 있는
  인상과 어긋난다고 판단했다.
- **링크 색(블루/퍼플)**은 채도를 낮춘 톤을 선택했다. 순색(`#0000FF`,
  `#FF00FF` 등)은 화면에서 튀고 원색 대비가 과해 눈이 쉽게 피로해지므로
  피했다. 동시에 "링크=파란색" 관습을 완전히 벗어나면 독자가 링크를 링크로
  인지하지 못할 위험이 있어, 관습은 유지하되 채도만 낮췄다.
- **면책 문구 박스(앰버 톤)**는 style-guide.md 7번에서 언급된 "이탤릭 대신
  배경색 박스" 검토와 연결된다. 앰버는 금융/재테크 콘텐츠에서 "투자 유의"를
  나타내는 데 흔히 쓰이는 색조이지만, 채도가 높은 경고색(예: 형광 노랑,
  빨강)은 과도한 경고 인상을 주고 톤앤매너에서 벗어나므로 옅게 눌렀다. 배경과
  텍스트 모두 계산상 8.28:1로 대비가 넉넉해 가독성 문제도 없다.
- **표 헤더 배경(옅은 그레이)**은 본문 배경과 구분은 되지만 시각적으로 튀지
  않는 최소한의 톤을 선택했다. 표 자체가 정보 스캔용이므로 헤더가 지나치게
  강조되면 오히려 본문보다 시선을 뺏는다.

전체적으로 채도가 높은 색(빨강, 형광색 계열 등)은 어느 용도에도 사용하지
않았다. 유일하게 채도를 준 곳은 링크(블루/퍼플)와 경고 박스(앰버)이며, 둘 다
"기능적으로 구분이 필요한 요소"에만 제한적으로 적용했다.

## 4. 구현 시 참고 (CSS 변수 제안)

실제 사이트 코드는 아직 없으므로 강제 사항은 아니지만, 개발팀이 CSS를 만들 때
참고할 수 있도록 변수명 예시를 남긴다.

```css
:root {
  --color-bg: #FFFFFF;
  --color-text: #333333;
  --color-heading: #1A1A1A;
  --color-link: #0B5FA5;
  --color-link-visited: #6A4C93;
  --color-warning-bg: #FFF3E0;
  --color-warning-text: #6B3E00;
  --color-table-header-bg: #F0F0F0;
  --color-table-header-text: #333333;
}
```

## 5. 향후 미확정 사항

- 다크모드 팔레트는 이번 범위에 포함하지 않았다. 필요해지면 별도 문서에서
  각 조합의 대비비를 새로 계산해야 한다(다크모드는 배경/전경이 반전되므로
  이 문서의 값을 그대로 반전 적용할 수 없다).
- 버튼, 알림(toast), 폼 요소 등 아직 사이트에 존재하지 않는 UI 요소의 색상은
  다루지 않았다. 실제로 필요해지는 시점에 추가한다.
